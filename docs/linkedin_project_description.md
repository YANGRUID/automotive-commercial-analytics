# LinkedIn and GitHub Project Copy

## Short LinkedIn description

I built an Automotive Commercial Analytics case study for a fictional Swiss quotation marketplace. It combines reproducible synthetic data, Python/Pandas ETL, PostgreSQL modelling, advanced SQL, an editable Power BI Project, a formula-driven Excel workbook, data-quality controls, an executed notebook, and management-ready commercial insights. It is portfolio work—not a production deployment or proprietary data.

## GitHub repository description

Automotive marketplace analytics case study: synthetic data, Python ETL, PostgreSQL fact constellation, advanced SQL, editable Power BI/DAX, Excel, data quality, testing, and business insights.

## Technical summary

- Fixed-seed generator: 50k customers, 100k raw inquiries, ~345k dealer quotes, 150 dealers, 2022–2025.
- Python/Pandas pipeline with extraction, normalization, type handling, deduplication, foreign-key validation, corrections, quarantine, anomaly flags, and audit metrics.
- PostgreSQL DDL with constraints, indexes, five reporting views, 24 analytical SQL queries, and 10 database quality checks.
- Power BI fact-constellation design, 55 explicit DAX measures, 59 bound PBIR visuals, PostgreSQL Import-mode partitions, and five report pages.
- Formula-driven Excel decision workbook, executed Jupyter notebook, pytest/Ruff checks, and GitHub Actions workflow.

## Business summary

The analytical solution shows how management can monitor demand, inquiry conversion, dealer competitiveness, first-response speed, channel quality, vehicle value, quote dispersion, and data operations. The generated evidence supports an eight-hour response SLA, a balanced dealer scorecard, referral-channel protection, SUV coverage, relative-spread monitoring for older vehicles, and a targeted anomaly-review process.
