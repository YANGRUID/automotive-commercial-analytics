# CV Project Entry

**Automotive Commercial Analytics — Swiss Marketplace Case Study**  
*Power BI | SQL | Python | PostgreSQL | DAX | Excel*

- Built a reproducible Python/Pandas ETL and PostgreSQL fact constellation for 99.8k synthetic vehicle inquiries and 343.1k dealer quotes, with controlled raw-data defects, quarantine, reconciliation, and automated tests.
- Built a source-controlled five-page Power BI Project with a TMDL semantic model, 55 explicit DAX measures, and 59 bound PBIR visuals; added a formula-driven Excel decision workbook for non-BI stakeholders.
- Used SQL and Python analysis to identify response-time, channel, dealer-competitiveness, vehicle-segment, and quote-dispersion patterns, translating results into clearly caveated management recommendations.
